# 密码保险箱

> AES-256 加密的本地密码管理器。Auto-Type 自动填充（URL 匹配防钓鱼）、TOTP 验证码、密码生成器、健康检查、Bitwarden 导入导出、Git 跨设备同步。

octopus 内置一个完整的密码管理器，所有数据用你的主密码派生密钥加密存储在本地。它的核心特色是 **Auto-Type 自动填充**——在浏览器登录页按一个键，自动匹配当前网站并填入账号密码，且用域名匹配防钓鱼。

## 进入与首次设置

### 入口

「设置 → 密码保险库」。这是一个设置页内的功能，不是独立窗口。

### 首次设置主密码

第一次使用会进入设置向导，设置**主密码**：

- **长度 ≥ 12 位**，且必须包含 **4 类字符**（大写、小写、数字、符号），实时显示规则勾选。
- 两次输入必须一致。

> ⚠️ **主密码不可找回！** 它是加密密钥的派生来源，遗忘后保险库里的数据**无法解密**。请务必妥善保管，建议配合 Git 同步在另一台设备保留可访问的副本。

> 📷 **待补截图**（`images/vault-setup.png`）：主密码设置向导（强度规则勾选）

### 三种状态

打开密码箱时的状态：

| 状态 | 表现 |
|------|------|
| 未初始化 | 显示设置向导（设主密码）|
| 已初始化未解锁 | 显示解锁对话框（输主密码）|
| 已解锁 | 显示主面板（条目 / 健康 / 导入导出三个标签）|

## 管理条目

主面板的「**密码条目**」标签：

### 左侧文件夹栏

- 所有条目 / 收藏 / 自定义文件夹（可新建、重命名、删除）/ **回收站**（带计数）。

### 搜索

按**名称 / 用户名 / 网址**模糊匹配。

### 新建 / 编辑

点右上「添加」或单击卡片编辑。编辑器字段：

| 字段 | 说明 |
|------|------|
| 名称 | 条目名 |
| 网址 | 每行一个，可填多条（用于 Auto-Type 匹配）|
| 用户名 | — |
| 密码 | 旁边有：眼睛（显隐）/ 🔑（调生成器）/ 复制；下方有强度条 |
| TOTP | Base32 密钥或 `otpauth://` 链接 |
| 备注 | — |
| 收藏 | 标星 |
| 文件夹 | 归类 |
| 使用时验证主密码 | 高敏感项：Auto-Type / 复制密码时强制再输主密码 |

### 删除

软删除 → 进**回收站**（二次确认）。回收站可「还原」/「永久删除」/「全部清空」。

## Auto-Type 自动填充（核心功能）

这是密码箱最有用的能力：在网站登录页按一个键，自动填账号密码。

### 怎么用

1. 在浏览器打开某个网站的登录页（光标点到用户名或密码框）。
2. 按 `⌘⇧S`（默认 Auto-Type 快捷键）。
3. octopus 抓取当前浏览器网址 → 弹出**选择浮窗** → 列出匹配该网站的条目。
4. 选条目 + 选填充模式 → 自动隐藏浮窗、浏览器回前台、模拟键盘填入。

> 📷 **待补截图**（`images/vault-autotype-picker.png`）：Auto-Type 选择浮窗（匹配的条目 + 填充模式图标）

### 三种填充模式

每个条目右侧的图标：

| 图标 | 模式 | 适合 |
|------|------|------|
| ⌨ | 用户名 + 密码 | 焦点在用户名框时（默认）|
| 🔑 | 仅填密码 | 焦点已在密码框，或 SPA 页面 Tab 不可靠 |
| @ | 仅填用户名 | 只需填用户名 |

另有「📋 复制用户名 / 复制密码」按钮，不自动填、只复制。

### URL 匹配（防钓鱼）

octopus 用**域名**匹配条目（基于 Mozilla 公共后缀列表算 eTLD+1，不是简单取最后两段——所以 `barclays.co.uk` 和 `evil.co.uk` 不会混淆）。

> 🔒 **关键安全行为**：如果抓不到浏览器网址，Auto-Type 会**返回空列表，绝不 fallback**——防止在钓鱼网站误填密码。你可以在浮窗里手动搜索条目强制填充。

### 在浮窗里新建条目

Auto-Type 浮窗里可以「+ 新增保险箱」快速建条目（极简 4 字段：名称 / 网址 / 用户名 / 密码），网址会预填当前页面。

## TOTP 验证码

条目编辑器的 TOTP 字段填入 Base32 密钥或 `otpauth://` 链接后：

- 已保存的条目会**每 5 秒刷新**显示验证码（6 位或 8 位，取决于站点配置；分两组）+ 倒计时秒数。
- 点复制按钮复制当前验证码。

## 密码生成器

两个入口，共用同一界面：

- **条目编辑器**：密码字段旁的 🔑 → 弹出生成器，「使用此密码」写回字段。
- **Action Bar**：输入框右侧的 🔑 按钮 → 弹出独立生成器浮窗，可「Auto-type」直接注入前台浏览器。

### 四种生成模式

| 模式 | 选项 |
|------|------|
| **随机字符** | 长度 5–128；大小写 / 数字 / 符号 / 避免易混字符开关 |
| **英文短语** | 词数 3–10；分隔符；首字母大写；含数字 |
| **中文短语** | 词数 3–8；分隔符；含数字；含符号（4096 词表）|
| **数字 PIN** | 长度 1–32 |

实时显示**密码强度**（按熵算，0–4：极弱 / 弱 / 一般 / 强 / 极强），可复制或重新生成。

> 📷 **待补截图**（`images/vault-generator.png`）：密码生成器（模式切换 + 强度指示）

## Bitwarden 导入导出

主面板的「**导入导出**」标签：

### 导入

- 支持 Bitwarden **未加密 JSON** 导出（`encrypted: false`），不支持加密导出。
- 选 `.json` 文件导入，返回导入 / 跳过 / 失败的数量。

### 导出

- 导出为 `vault-export-YYYY-MM-DD.json`（**明文**）。
- 界面有醒目警告：导出文件含所有密码明文，请妥善保管。

> ⚠️ 导入导出都是明文操作，用完及时删除临时文件。

## Git 跨设备同步

入口：「设置 → Git 同步」子标签（**不需要解锁密码箱**也能配）。

### 前提

- 系统装了 `git` + 配好 SSH key 认证。
- 一个 **Private（私有）仓库**（GitHub / Gitee 等）。

### 配置流程

| 场景 | 操作 |
|------|------|
| 首次启用（A 机）| 填远程仓库地址 → 「启用同步」→ 推送本地数据 |
| 从远程克隆（B 机）| 「从远程克隆」→ 拉取数据 |

远程地址是列表式的，可加多个、测试连接、删除。HTTPS 地址会自动检测是否私有库（公有库被拒）；SSH 地址需自行确认私有。

### 自动同步

启用后**每小时**自动同步一次（CPU 空闲时触发）。同步内容：加密的密码箱数据 + 热词数据。

### 主密码冲突

如果远程和本地主密码不一致（比如两台设备改了不同密码），会弹窗让你二选一：

- 「以远程为准」→ 输入远程主密码。
- 「以本地为准」→ 输入本地主密码。

> 💡 建议两台设备用同一个主密码，避免冲突。

> 📷 **待补截图**（`images/vault-sync.png`）：Git 同步面板（远程列表 + 上次同步时间）

## 自动锁定与安全

### 自动锁定

默认 **3 分钟**无操作自动锁定（可设 30 秒 / 1 分 / 3 分 / 5 分 / 15 分 / 永不）。机制：保险库标签离开前台（切标签 / 关窗 / 应用失焦）超过设定时间即锁。

> 切换设置标签或关闭窗口会**立即锁定**，防止偷窥。「永不锁定」会显示降低安全的警告。

### 错误退避

主密码输错次数越多，等待越久（指数退避：1 → 2 → 4 → 8 → 16 → 30 秒），防暴力破解。

### 加密方式

- **AES-256-GCM** 加密 + **Argon2id** 派生密钥。
- **不依赖系统钥匙串**（macOS 未签名限制），主密码派生加密密钥。

### 高敏感项保护

勾了「使用时验证主密码」的条目，Auto-Type 或复制密码时后端会**强制再校验主密码**（开发者工具也绕不过）。

## 常见问题

**Q：忘记主密码怎么办？**
**无法找回**。主密码是加密密钥来源，遗忘后数据不可解密。如果你配了 Git 同步，在另一台还记得密码的设备上可以访问。

**Q：Auto-Type 弹出来是空的？**
可能抓不到浏览器网址（权限问题）——这是**防钓鱼设计**，不会乱填。在浮窗搜索框手动搜条目强制填充。也检查条目的「网址」字段是否填对。

**Q：Auto-Type 填错了位置？**
选对填充模式：焦点在用户名框用「用户名+密码」，焦点在密码框用「仅填密码」。SPA 页面（如网页邮箱）Tab 键不可靠时用「仅填密码」。

**Q：怎么从 Bitwarden 迁移？**
在 Bitwarden 导出**未加密 JSON**，然后在「导入导出」标签导入。不支持加密导出。

**Q：两台设备怎么同步？**
配 Git 同步（私有仓库），每小时自动同步。详见上文「Git 跨设备同步」。

**Q：密码箱数据存在哪？**
加密存在 `~/.octopus/octopus.db` 数据库里。离开应用无法直接读取明文。

**Q：自动锁定太频繁？**
在密码箱顶部把自动锁定超时调大，或设「永不」（会警告降低安全）。
