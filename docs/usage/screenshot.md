# 截图与标注

> 区域截图、滚动长截图、丰富的标注工具、贴图浮窗。截完即用——OCR、翻译、复制、保存一步到位。

octopus 的截图不只是「截一张图」，而是一个完整的截图工作流：框选 → 标注 → 后续处理（OCR / 翻译 / 钉在屏幕 / 复制 / 保存）都在同一个界面完成。

> 📷 **待补截图**（`images/screenshot-overlay.png`）：截图进行中——暗色遮罩 + 选区 + 工具栏

---

## 快速开始

1. 按 `⌘⇧X`（或托盘菜单「开始截图」）。
2. 屏幕变暗，**拖动鼠标框选区域**。
3. 选区下方弹出工具栏，可标注（箭头、文字、马赛克……）。
4. 按 `↵` 确认——截图自动复制到剪贴板，并存入剪贴板历史。

> 支持多显示器：每个屏幕一个全屏遮罩窗口，可在任意屏截图。

---

## 区域选择

框选出选区后：

- 选区四角和边上有 **8 个手柄**，可拖动调整大小，旁边显示尺寸数值。
- 键盘快捷操作：

| 按键 | 作用 |
|------|------|
| `↵` | 确认截图（复制 + 入库）|
| `⎋` | 取消 |
| `⌘Z` | 撤销标注 |
| `⌘⇧Z` | 重做 |
| `⌫` / `Delete` | 删除选中的标注 |

> 📷 **待补截图**（`images/screenshot-selection.png`）：选区 + 8 手柄 + 尺寸标注

## 标注工具栏

框选后下方弹出工具栏。工具按组分类，同一个按钮可以切换子模式（长按或再次点击）：

> 📷 **待补截图**（`images/screenshot-toolbar.png`）：完整标注工具栏

| 工具组 | 包含 | 说明 |
|--------|------|------|
| 选择 | 选择 | 选中已绘制的标注进行调整 / 删除 |
| 形状 | 矩形 / 椭圆 / 菱形 | 可切换实心 / 空心填充 |
| 线条 | 直线 / 箭头 / 画笔 / 荧光笔 / 序号 | 序号会自动递增编号 |
| 文字 | 文字 | 可设字号 |
| 马赛克 | 像素化 / 高斯模糊 / 黑条遮挡 | 打码敏感信息 |
| 水印 | 水印 | 弹输入框输入水印文字（留空 = 清除）|
| 擦除 | 橡皮擦 / 撤销 / 重做 / 清空 | — |

每个工具点开后有弹出面板，可调：**颜色**（预设色 + 调色板）、**粗细**、**字号**、**填充模式**。

> 💡 标注只会画在选区内（超出部分自动裁剪），不用担心画到外面。

## 滚动截图（长截图）

需要截一个很长的网页 / 文档时用滚动截图，自动拼接成一张长图。

1. 框选区域后，点工具栏的「**滚动截图**」按钮（滚动图标）。
2. 进入手动滚动模式——你用鼠标滚轮滚动目标内容。
3. 旁边实时显示**拼接预览**，看着画面往下拼。
4. 拼够了，点绿色的「复制」按钮结束。

> ⚠️ 滚动截图窗口鼠标穿透，按 `⎋` 取消时如果没反应，用全局快捷键或在选区外右键取消。

## 贴图浮窗（Pin）

想把截图「钉」在屏幕上随时参考？用贴图功能。

- 框选后，点选区角落的「**贴图**」按钮（图钉图标）。
- 截图变成一个**置顶浮动窗口**浮在所有窗口之上。
  - **拖拽移动**：按住左键拖。
  - **滚轮缩放**：以鼠标位置为中心放大缩小。
  - **关闭**：鼠标移到窗口上，点右上角的红色关闭按钮。

> 📷 **待补截图**（`images/screenshot-pin.png`）：贴图浮窗钉在屏幕上

## 截图后能做什么

工具栏右侧有一排业务按钮：

| 按钮 | 作用 |
|------|------|
| 🔤 **OCR** | 识别选区文字，结果进图文编辑器（详见 [OCR 模块](./ocr.md)）|
| 🌐 **翻译** | OCR 识别后即时翻译，弹出译文浮窗（详见 [翻译模块](./translate.md)）|
| ▦ **二维码识别** | 识别图片里的二维码（支持多码），白卡展示，可复制 |
| 📜 **滚动截图** | 见上文 |
| 💾 **保存到文件** | 另存为图片文件 |
| ✅ **确认 / 复制** | 复制到剪贴板 + 存入剪贴板历史 |
| ✕ **取消** | 放弃 |

## 设置

截图相关设置在「设置 → 常规」：

| 设置项 | 作用 |
|--------|------|
| 截图快捷键 | 默认 `⌘⇧X`，可改 |
| 默认水印 | 可设一个默认水印文字 |

截图本身不需要复杂配置——开箱即用。截图会自动存入剪贴板历史（JPEG 压缩存库 + 原图存 `~/Documents/octopus/screens/`）。

## 常见问题

**Q：截图是黑屏？**
没授予**屏幕录制权限**。去「系统设置 → 隐私与安全性 → 屏幕录制」开启 octopus。升级应用后权限可能失效，需删除旧条目重新添加。

**Q：截图快捷键按了没反应？**
检查是不是被其他截图软件（如 CleanMyMac、Snipaste）占用了同一个快捷键；也可在「设置 → 常规 → 快捷键」改一个。

**Q：截图保存在哪？**
截图复制到剪贴板的同时，原图存在 `~/Documents/octopus/screens/`，压缩版存进数据库。打开「剪贴板历史」（`⌥C`）切到「图片」标签可以查看所有历史截图。

**Q：贴图浮窗能置顶在所有窗口上吗？**
可以，贴图浮窗默认就是置顶的（always-on-top）。
