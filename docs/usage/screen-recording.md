# 屏幕录制

> 录制全屏 / 窗口 / 区域，支持实时标注、系统声音 + 麦克风双音轨、导出 GIF、自动生成字幕。

> ⚠️ **平台限制：屏幕录制仅支持 macOS**（基于系统 ScreenCaptureKit 框架）。Windows / Linux 暂不支持。

---

## 快速开始

1. 按 `⌘⇧R`（或托盘菜单「开始录屏」）。
2. 弹出**配置浮窗**，选择录制源（全屏 / 窗口 / 区域）和音频选项。
3. 点「开始录制」。
4. 录制中可暂停、实时标注（仅区域录制）。
5. 按 `⎋` 停止，视频自动保存到 `~/Documents/octopus/recordings/`。

> 📷 **待补截图**（`images/record-config.png`）：录制前的配置浮窗

## 录制源

配置浮窗顶部三个标签切换录制源：

| 源 | 说明 |
|----|------|
| **全屏（display）** | 录制整个显示器（多显示器可选）|
| **窗口（window）** | 录制单个应用窗口 |
| **区域（area）** | 拖框框选一块区域录制（默认）|

> 💡 **只有「区域」录制支持实时标注**——因为区域录制用一个透明覆盖层，标注会被录进视频。全屏 / 窗口录制没有覆盖层，录制时只有右下角的控制浮条。

---

## 配置选项

配置浮窗里的选项（高级选项默认收起）：

| 选项 | 默认 | 说明 |
|------|:----:|------|
| 系统声音 | 开 | 录制系统播放的声音 |
| 麦克风 | 开 | 录制麦克风（旁白）|
| 帧率 | 30 | 15 / 30 / 60 |
| 编码 | h264 | h264 / hevc（hevc 体积更小但兼容性稍差）|
| 隐藏光标 | 关 | 不录鼠标指针 |
| 停止后定位文件 | 可配 | 停止后在 Finder 里显示视频文件 |
| 保存目录 | `~/Documents/octopus/recordings/` | 可改 |

> 高级选项**只在当前录制会话生效，不会持久化**——每次录制都要重新设。

> 📷 **待补截图**（`images/record-advanced.png`）：展开的高级选项

## 录制中的控制

录制开始后，根据录制源不同，控制方式不同：

### 全屏 / 窗口录制

桌面**右下角**出现一个控制浮条（pill）：红点 + 录制时长 + 暂停按钮 + 停止按钮。

### 区域录制

整个录区被一个透明覆盖层覆盖，**支持实时标注**（复用截图的标注工具栏，但不含荧光笔和水印）。标注会实时录进视频。

### 通用控制

| 操作 | 作用 |
|------|------|
| `⌘⇧R` | 暂停 / 恢复（toggle）|
| `⎋` | 停止录制（停止后 `⎋` 的全局监听会自动注销，不影响其他窗口）|
| 托盘菜单「停止录屏」| 停止 |
| 控制浮条按钮 | 暂停 / 停止 |

> 录制时托盘菜单项会变成「● 停止录屏 ⎋」，带红点提示。

> 📷 **待补截图**（`images/record-control-pill.png`）：右下角控制浮条 + 录制时长

## 录制产物

### 视频格式

默认输出 **MP4**（h264 或 hevc）。

### 双音轨

系统声音和麦克风**分别录制成两条独立音轨**。

- 把视频拖到播放器，切换音轨能分别听。
- 在「录屏管理」里点「**合并音轨**」会用 ffmpeg 把两轨混音另存为 `xxx_merged.mp4`（需要装 ffmpeg）。

### GIF 导出

在「录屏管理」里点「导出 GIF」。需要 ffmpeg，没装的话按钮会禁用并给出安装引导。

### 自动字幕

在「录屏管理」里点「转字幕」，octopus 会：

1. 提取音轨。
2. 用 ASR 引擎识别语音，生成 `.srt` 字幕文件。
3. 可选：用 LLM 润色字幕。

> 字幕文件和视频同名，扩展名为 `.srt`（如 `recording.mp4` → `recording.<音轨>.srt`）。

> 📷 **待补截图**（`images/record-subtitle.png`）：转字幕对话框（可选润色 + 选模型）

## 录屏管理

打开「设置 → 录屏管理」可以看到所有录制记录：

> 📷 **待补截图**（`images/record-management.png`）：录屏管理列表

每条记录可以：

- **重命名**
- **收藏**（标星）
- **导出 GIF**
- **合并音轨**
- **转字幕**
- **删除**（会询问是否同时删磁盘文件）
- **批量删除**（多选）

顶部显示当前录制状态 + 实时时长 + 开始 / 暂停 / 恢复按钮。

## 常见问题

**Q：录出来是黑屏 / 没有画面？**
没授予**屏幕录制权限**。去「系统设置 → 隐私与安全性 → 屏幕录制」开启 octopus。升级应用后需删除旧条目重新添加并重启。

**Q：录出来没有声音？**
检查：① 配置浮窗的「系统声音 / 麦克风」是否打开；② 麦克风权限是否授予；③ 系统声音录制在 macOS 上可能需要额外的虚拟音频驱动（取决于 macOS 版本）。

**Q：怎么把系统声音和麦克风混到一起？**
默认是两条独立音轨。在「录屏管理」里点该记录的「合并音轨」（需要 ffmpeg）。

**Q：导出 GIF 按钮是灰的？**
没装 ffmpeg。终端运行 `brew install ffmpeg` 安装。

**Q：实时标注为什么只有区域录制有？**
全屏 / 窗口录制没有覆盖层（否则会把自己录进去）。要边录边标注，选「区域」源。

**Q：录制文件在哪？**
默认 `~/Documents/octopus/recordings/`，可在配置浮窗或设置里改保存目录。
