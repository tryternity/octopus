# OCR 文字识别

> 把图片里的文字提取出来。截图 OCR、剪贴板图片 OCR、图片预览文字选择层、二维码识别。

octopus 内置 PaddleOCR 引擎（PP-OCR），能把图片中的文字识别成可编辑、可复制的文本，并按版面结构输出。它不是一个独立窗口，而是融入截图、剪贴板、图片预览等多个场景的「把图变成字」能力。

## 四个触发入口

### 1. 截图后 OCR

截图框选区域后，点工具栏的「**OCR**」按钮（OCR 图标）：

- 识别选区内的文字。
- 结果打开图文编辑器，左边图片标签、右边文本标签，可编辑。
- 文字同时存入剪贴板历史。

> 详见 [截图与标注](./screenshot.md) 的「截图后能做什么」。

### 2. 剪贴板图片 OCR

在「剪贴板历史」（`⌥C`）里找到图片类型的条目，点该条目的 **OCR 按钮**（扫描图标），即可识别图片中的文字。

### 3. 图片预览 OCR（手动三态）

打开图片预览时默认是干净的图片（不自动识别）。点工具栏的 **OCR 按钮**：

- **第 1 次点击**：识别文字并进入「可选」模式——图片上叠加透明文字层，可直接用鼠标拖选、复制文字（像 macOS 的「实况文本」）。
- **再点一下**：切换到「遮罩」模式——纯文字白底黑字显示（不可选，适合校对识别结果）。
- **继续点**：在「可选」和「遮罩」之间来回切换。

识别结果同时存入剪贴板历史（类型为 `OCR`），可搜索、复用。

> 📷 **待补截图**（`images/ocr-image-preview.png`）：图片预览中的透明文字层（可拖选）

### 4. 二维码识别

截图后点工具栏的「**二维码识别**」按钮，识别图片里的二维码（支持一张图多个码），结果用白卡展示，可单个复制或全部复制。

## 识别引擎

| 引擎 | 说明 |
|------|------|
| **PaddleOCR PP-OCRv6-small** | 默认引擎，支持中英文，CTC 已支持空格，英文无需额外分词 |
| PaddleOCR PP-OCRv5 | 旧版，CTC 不输出英文空格，需词库分词 |

识别流程：检测（det）→ 方向分类（cls）→ 识别（rec），基于 ONNX Runtime 推理。

**长图处理**：图片高度超过 1600px 时会自动分块识别（每块 1280px，重叠 200px），保证长截图也能完整识别。

**内存释放**：OCR 引擎空闲 60 秒后自动释放模型内存，下次使用自动重载（macOS 下进程内存数值可能不会立即下降，属正常现象）。

---

## 结果怎么用

- **图文编辑器**：截图 OCR 和剪贴板图片 OCR 会打开图文编辑器，图片 + 文本双标签，文本可编辑，`⌘S` 保存回数据库。
- **透明文字层**：图片预览的 OCR 结果直接叠加在图片上，用浏览器剪贴板复制。
- **剪贴板历史**：所有 OCR 结果都会存入剪贴板历史（类型为 `OCR`），可搜索、复用。
- **翻译**：截图后点「翻译」会先 OCR 再翻译，弹出译文浮窗。

识别结果按版面输出为结构化文本（识别标题 / 列表 / 段落，中英文之间自动处理空格）。

## 切换 OCR 模型

1. 打开「设置 → 模型管理」。
2. 切到「**OCR**」标签。
3. 列表显示可下载的 OCR 模型：点「下载」（首次）→「激活」。
4. 顶部横幅显示当前激活的模型。

> ⚠️ **切换 OCR 模型后需要重启应用才生效**（会提示「已切换，重启后生效」）。

## 注意事项

**同一时刻只能跑一个 OCR 任务。** 如果别处正在识别，你再触发会被拒绝，并给出提示：

- 剪贴板 / 图片预览的 OCR 按钮会显示琥珀色三角（约 1.8 秒）。
- 截图时屏幕中央会弹「前一个 OCR 还未完成，请稍后」。
- 等之前的完成再重试即可。

> 💡 OCR 失败或图片里没有可识别的文字框时，会静默降级，不影响你正常看图。

## 常见问题

**Q：识别准确率不高？**
① 确保图片清晰、文字区域对比度够；② PP-OCRv6 比 v5 准，确认激活的是 v6；③ 手写体、艺术字、严重倾斜的文字识别效果有限。

**Q：英文单词连在一起没有空格？**
用 PP-OCRv6-small（默认），它已支持英文空格。如果用的是 v5，英文需要词库分词，建议切换到 v6。

**Q：切换模型后没变化？**
OCR 模型切换需要**重启应用**才生效（会有提示）。

**Q：OCR 按钮点了没反应？**
可能上一个 OCR 任务还没跑完（全局同时只能一个）。等几秒再试，或看屏幕中央的提示。
