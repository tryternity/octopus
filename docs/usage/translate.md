# 翻译

> 语音识别结果、截图、选中文本的即时翻译。本地引擎离线可用，云端 LLM 翻译质量更高。

octopus 的翻译能力融入多个场景：语音听写时实时翻译、截图后翻译图片里的文字、选中任意文本翻译。它不是一个独立窗口，而是「需要翻译时随手可用」的能力。

## 四个触发入口

### 1. 语音识别结果翻译

在[语音听写](./asr-dictation.md)的结果窗口工具栏点「翻译」按钮 + 模式下拉：

| 模式 | 行为 |
|------|------|
| 关闭 | 不翻译 |
| 手动 | 点「立即翻译」才译 |
| 自动 4s / 8s / 12s | 识别结果稳定 N 秒后自动重译 |

译文显示在结果窗口的译文区，随识别流式更新。

### 2. 截图翻译

截图框选后点工具栏的「**翻译**」按钮：

1. OCR 识别选区文字。
2. 关闭截图窗。
3. 弹出独立的**译文浮窗**（鼠标上方居中，置顶不抢焦点）。
4. 流式渲染译文，可复制、按 `⎋` 或 `✕` 关闭。

### 3. 图文编辑器对照翻译

在图文编辑器的文本标签里切「原文 / 译文对照」模式，点翻译按钮翻译当前文本。已有译文时再翻会二次确认覆盖。

### 4. Action Bar 选中翻译

在 [Action Bar](./action-bar.md) 里选中一段文本，执行配了翻译动作的菜单项（或 `auto_translate`），译文显示在浮窗。

## 翻译引擎

octopus 支持本地和云端两类引擎：

### 本地引擎（离线可用）

| 引擎 | 说明 |
|------|------|
| **Opus-MT** | 轻量（约 30M / 方向），**仅中英互译**，本地快速 |
| **m2m100** | 100+ 语言互译，int8 量化，本地 |

### 云端 LLM 引擎（OpenAI 兼容协议）

覆盖 **6 家服务商**，配置差异仅在 API 地址和密钥：

- OpenAI
- DeepSeek
- 阿里云百炼 DashScope
- 智谱 BigModel
- Moonshot（Kimi）
- MiniMax

### 兜底机制

如果没激活翻译模型，或云端模型没填 API Key，octopus 会**自动回退到已激活的润色 LLM**（用翻译提示词）——保证你到翻译时不会突然报错。

---

## 语言方向（自动检测）

翻译**全自动判断中英方向**，无需手动选：

- 文本含中文 / 日文 / 韩文字符 → 翻译成**英文**
- 否则 → 翻译成**中文**

> 💡 本地 Opus-MT 只支持中英互译；m2m100 理论支持 100+ 语言，但当前界面只暴露中英自动检测。需要其他语言用云端 LLM 引擎。

---

## 流式翻译

翻译是**流式**的——长文本会按段落、句子切分，逐句翻译逐句显示，不用等全部翻完。

> 💡 轻量本地模型对整段长文本翻译容易「只译第一句」，所以会自动切短句分别翻译，质量更稳定。

## 配置翻译模型

1. 打开「设置 → 模型管理」。
2. 切到「**翻译**」标签。
3. 顶部横幅显示当前激活的引擎和策略（本地 / 云端 / 兜底 LLM）。

### 本地模型

列表里点「下载」（首次）→「激活」。opus-mt、m2m100 都是本地模型。

### 云端模型

点「添加模型」，填表单：

- **服务商**：选预设（OpenAI / DeepSeek / 阿里 / 智谱 / Moonshot / MiniMax），选了会自动填 API 地址。
- **模型名**：如 `gpt-4o-mini`、`deepseek-chat`。
- **API Key**：你的密钥。
- **是否流式** / **是否思考模型**。

填完「激活」即用。

> 🔒 启用密码箱后，API Key 会加密存储，翻译时透明解密。

## 下载加速

下载本地模型时，如果国内访问慢，可以在设置里配置**下载镜像**（如 `https://hf-mirror.com`），留空则用官方源。

## 常见问题

**Q：翻译报错 / 没反应？**
检查：① 是否激活了翻译模型；② 云端模型的 API Key 是否填对；③ 网络。没激活时会自动用润色 LLM 兜底，所以通常会静默翻译。

**Q：怎么翻译成英语以外的语言？**
本地引擎只支持中英。需要日语、韩语等，用云端 LLM 引擎（但当前界面只暴露中英自动检测方向）。

**Q：截图翻译的浮窗怎么关？**
按 `⎋` 或点浮窗的 `✕`。浮窗是置顶不抢焦点的，关了不影响你当前操作。

**Q：翻译速度慢？**
本地 Opus-MT 最快（离线）。云端 LLM 取决于网络和服务商响应。长文本会切句流式翻译，不用干等。

**Q：API Key 安全吗？**
启用密码箱后，API Key 加密存储。没启用密码箱则明文存在数据库里。
