# 剪贴板历史

> 自动记录你复制过的所有内容——文本、图片、语音、文件。全文搜索、粘贴队列、收藏，再也不怕复制覆盖。

octopus 在后台持续监听系统剪贴板，把每次复制的内容都记下来。按 `⌥C` 随时调出历史，搜索、粘贴、复用。

> 📷 **待补截图**（`images/clipboard-window.png`）：剪贴板历史浮窗（搜索框 + 分类标签 + 条目列表）

---

## 快速开始

1. 平时正常复制东西（`⌘C`），octopus 会自动记录。
2. 按 `⌥C` 打开剪贴板浮窗。
3. **双击任意条目** = 粘贴到当前光标位置（前台应用）。

就这么简单。剪贴板浮窗是透明置顶的，随时呼出、随时关闭。

---

## 浮窗里能做什么

### 分类筛选（标签栏）

顶部有 8 个分类标签，点切或用键盘 `←→` / `⌥字母` 切换：

| 标签 | 内容 |
|------|------|
| 全部 | 所有条目 |
| ⭐ 收藏 | 标星的条目（不会被自动清理）|
| 🎙 语音 | 语音识别的结果 |
| 文本 | 纯文本（含链接）|
| 🔤 OCR | OCR 识别的文本 |
| 🖼 图片 | 截图 / 复制的图片 |
| 📎 文件 | 复制的文件 |
| 📋 队列 | 粘贴队列里的条目 |

### 搜索

顶部搜索框，输入关键词即搜。**全文搜索**支持：

- **≥ 3 个字符** → 走快速全文索引。
- **< 3 个字符** → 降级为子串匹配。

> 💡 只搜文本 / 语音 / OCR 内容，图片和文件不参与搜索。

### 粘贴回

- **双击条目** = 粘贴到前台应用（固定行为）。
- 键盘选中后按 `↵` 同样粘贴。

### 复制（不粘贴）

点条目左侧的**类型图标** = 单击复制（不粘贴，闪绿 + 「已复制」提示）。

### 收藏

点条目的**星标**按钮收藏。收藏项：

- 永久保留，不受自动清理影响。
- 任何删除操作（单删 / 批量清理）都自动跳过收藏。

### 删除

- **单条删除**：两步确认——点一次变红「再点确认」，再点才删。
- **批量清理**：底栏「清理」按钮，一键删当前标签下所有非收藏条目。

### 粘贴队列（Paste Stack）

需要按顺序粘贴一堆内容？用粘贴队列：

1. `⌘ + 点击` 多个条目，它们会被编号 ①②③ 加入队列。
2. 切到目标应用，光标定位好。
3. 按 `⌘⇧V` ——**逐条弹出**队列内容，按先进先出顺序粘贴。
4. 每按一次粘贴一条，直到队列清空。

> 📷 **待补截图**（`images/clipboard-paste-queue.png`）：粘贴队列（带序号的条目）

### 链接识别

文本条目里的链接（含 `http://`、域名、`localhost:端口`、IP:端口）会自动识别，点链接图标直接在浏览器打开。

### 悬停预览

鼠标悬停在条目上（或键盘选中），右侧弹出 200×200 预览（文本片段 / 图片缩略图 / 文件路径）。**默认开启**，可在浮窗标题栏的「眼睛」按钮关闭。

> 📷 **待补截图**（`images/clipboard-preview.png`）：悬停预览弹出

## 键盘导航（脱离鼠标）

剪贴板浮窗完全支持键盘操作：

| 按键 | 作用 |
|------|------|
| `↑` `↓` | 上下移动选中（边界夹紧，不循环）|
| `↵` | 粘贴选中项 |
| `⎋` | 清空搜索；再按隐藏浮窗 |
| `←` `→` | 搜索框空时循环切标签 |
| `⇥` / `⇧⇥` | 总是循环切标签 |
| `⌃1`–`⌃7` | 直接跳到前 7 个标签 |

## 条目类型

剪贴板历史统一存储 5 类内容：

| 类型 | 来源 |
|------|------|
| **文本** | 复制的文字（含链接）|
| **语音** | 语音识别的结果（来自听写模块）|
| **OCR** | OCR 识别的文本（来自 OCR 模块）|
| **图片** | 截图、复制的图片（原图存文件，缩略图入库）|
| **文件** | 复制的文件（记录路径）|

## 边缘吸附（仅 macOS）

把浮窗拖到屏幕边缘（≤10px）会自动收缩成一条细线，不挡视线。鼠标移上去或点击展开，失焦后自动收缩。

## 设置

剪贴板相关设置在「设置 → 剪贴板」：

| 设置项 | 默认 | 作用 |
|--------|:----:|------|
| 启用剪贴板监听 | 开 | 总开关，关了就不记录（浮窗标题栏也有快捷开关）|
| 最大条数 | 1000 | 超出自动清理（不含收藏）|
| 自动清理天数 | 30 | 超过 N 天的非收藏条目自动删 |
| 浮窗快捷键 | `⌥C` | 可改 |
| 粘贴队列出栈 | `⌘⇧V` | 可改 |
| 浮窗主题 | 浅色 | 浅色 / 深色毛玻璃 / Nord / 自定义 |

> 自动清理在启动时跑一次，之后每小时跑一次。改了条数 / 天数限制，1 小时内自动生效。

## 常见问题

**Q：剪贴板没记录东西？**
检查「设置 → 剪贴板 → 启用剪贴板监听」是否打开（浮窗标题栏也有快捷开关）。

**Q：搜索搜不到？**
全文索引需要 ≥3 个字符，少于 3 个字符走子串匹配。注意图片和文件不参与搜索。

**Q：原图丢了，缩略图显示感叹号？**
原图存在 `~/Documents/octopus/screens/`，如果被手动删了，剪贴板里只剩缩略图（显示「原图丢失」）。建议别手动删那个目录。

**Q：粘贴队列怎么清空？**
按 `⌘⇧V` 把队列里的条目逐个粘贴完就清空了，或切到「队列」标签手动删除。

**Q：浮窗挡住视线了？**
macOS 上把浮窗拖到屏幕边缘会自动收缩成细线；也可直接按 `⌥C` 关闭。
