# 终端

> 内嵌终端（xterm.js + 系统 shell），多标签、文件树、文件拖入、搜索、AI agent 联动。不用离开 octopus 就能敲命令。

octopus 内置一个功能完整的终端，支持多标签、文件树浏览、文件拖入、语音输入。它特别适合配合 Action Bar 的 Agent 动作使用——召唤 AI agent（如 Claude Code）在这里跑。

## 打开终端

终端没有全局快捷键，两种打开方式：

| 方式 | 行为 |
|------|------|
| **托盘菜单 → 新建终端** | 每次点都开一个**新窗口**（多实例）|
| **Action Bar 的 Agent 动作** | 打开**专用窗口**，自动写入并执行命令（如 `claude`）|

> 💡 Action Bar 触发的 agent 终端是单例窗口——已存在就聚焦 + 新开标签，不存在才建窗。

---

## 多标签

一个终端窗口里可以开多个标签（每个标签独立 shell 会话）：

| 操作 | 作用 |
|------|------|
| `⌘T` | 新建标签 |
| 点 `+` 按钮 | 新建标签 |
| 右键 → 新建 tab | 新建标签 |
| 双击标签标题 | 内联重命名 |

> 📷 **待补截图**（`images/terminal-tabs.png`）：多标签 + 重命名

## 布局切换

终端顶部标签栏可以切换成**左侧边栏列表**样式，点按钮切换，记忆你的偏好。

- 标签栏样式：顶部一排标签。
- 侧栏样式：左侧列表，适合标签多的时候。

---

## 文件树面板

终端左侧可以打开一个**文件树面板**，显示当前标签的工作目录树：

- 点按钮开关。
- 拖拽边缘调宽度。
- 显示当前标签的目录（`cd` 后自动跟随）。

## 文件拖入

两种拖入方式，路径会自动转义：

| 来源 | 行为 |
|------|------|
| **Finder 拖入**（OS 原生）| 粘贴**转义后的绝对路径** |
| **文件树拖入**（内部节点 → 画布）| 粘贴**相对当前目录的转义路径** |

> 💡 把文件从 Finder 或文件树直接拖到终端画布，路径就进去了，省去手敲。

---

## 搜索

按 `⌘F` 弹出搜索浮层，搜索终端里的输出内容。

---

## 右键菜单

右键终端画布：复制 / 粘贴 / 全选 / 清屏。

> 💡 macOS 的 WKWebView 剪贴板有限制，复制用兜底方案（文本框 + execCommand），粘贴同理。基本可用，少数情况可能需要手动 `⌘V`。

---

## 字号与字体

| 操作 | 作用 |
|------|------|
| `⌘=` | 放大字号 |
| `⌘-` | 缩小字号 |

字号范围 8–32，即时生效并记忆。默认字号 **13**，默认字体 **Menlo**（可在设置里改）。

---

## 语音输入联动

当终端在前台时，[语音听写](./asr-dictation.md)的识别结果可以**直接写入终端**（绕过界面，最可靠）。对着终端说话，命令就进去了——适合口述长命令或不想打字时。

---

## agent 状态徽章

如果终端里跑的是 AI agent（通过 Action Bar 启动），标签标题旁会显示**彩色状态徽章**：

| 徽章 | 状态 |
|------|------|
| 🟡 琥珀脉冲 | agent 工作中 |
| 🔴 红色铃铛 | agent 需要注意（等你回应）|
| 淡出 | agent 完成 |

---

## 工作目录追踪

终端会感知 shell 的工作目录变化（OSC 7 序列）：`cd` 到别的目录后，文件树和新标签都会跟随到新目录。

---

## 设置

终端的设置项较少，主要是字体：

| 设置项 | 默认 | 作用 |
|--------|:----:|------|
| 字号 | 13 | 也可在终端里用 `⌘=/-` 调 |
| 字体 | Menlo | 单个字体族名 |

> 终端画布固定深色（`#0c0c0f`），不随主题变化；标签栏 / 侧栏随主题自适应。

## 常见问题

**Q：终端在哪打开？**
终端没有全局快捷键。点**托盘菜单 → 新建终端**，或通过 Action Bar 的 Agent 动作触发。

**Q：怎么改字体？**
在终端里用 `⌘=/-` 调字号；字体在设置里改（目前暴露的设置项主要是字体）。

**Q：复制粘贴不灵？**
macOS WKWebView 的剪贴板有限制，右键菜单的复制 / 粘贴用了兜底方案。如果不行，手动 `⌘C` / `⌘V`。

**Q：文件树怎么跟随目录？**
终端会自动追踪 shell 的 `cd`（需要 shell 支持 OSC 7，现代 shell 如 zsh / fish 默认支持）。新标签会继承当前标签的目录。

**Q：能同时开多个终端窗口吗？**
可以。托盘菜单每次点「新建终端」都开一个新窗口。Action Bar 触发的 agent 终端则是单例（聚焦或新标签）。
