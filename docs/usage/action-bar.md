# Action Bar 命令面板

> 类 Alfred / Raycast 的快捷启动器。搜应用、搜文件、搜书签、做计算、执行命令、召唤 AI——一个浮窗搞定。

Action Bar 是 octopus 的「万能入口」。按 `⌥D` 唤起一个浮在所有窗口上的搜索框，输入即搜，回车即执行。它有两种身份：没选中文本时是**启动器**，选中文本 / 文件时是**上下文动作面板**。

> 📷 **待补截图**（`images/actionbar-launcher.png`）：Action Bar 启动器模式（居中搜索框 + 搜索结果）

## 唤起

按 `⌥D`（默认，可改）唤起 / 隐藏（toggle）。

配置位置：「设置 → 常规 → 快捷键」，标签「操作面板」。

---

## 两种模式

| 模式 | 触发条件 | 表现 |
|------|---------|------|
| **启动器** | 没选中文本时唤起 | 主屏居中弹出，只有搜索框 |
| **上下文动作面板** | 选中文本 / 文件时唤起 | 在鼠标位置弹出，带菜单条（对选中内容执行动作）|

> 💡 选中文本后按 `⌥D`，Action Bar 会带着选中的内容弹出，直接对你选的东西执行动作（翻译、AI 处理、复制路径等）。

## 能做什么

### 搜索（启动器模式）

输入即搜，结果按频次加权排序：

| 来源 | 说明 |
|------|------|
| **应用** | 自动扫描 `/Applications` 等目录（含中文化别名，如微信）|
| **文件** | 走系统搜索（macOS `mdfind`）|
| **书签** | 浏览器书签 |
| **计算器** | 输入算式直接出结果，可复制 |
| **URL 检测** | 输入网址直接打开浏览器 |

### 执行动作（上下文模式）

选中内容后，菜单项的**动作类型**：

| 类型 | 作用 |
|------|------|
| **AI** | 选中文本发给 LLM 处理（填 `auto_translate` 自动中英互译）|
| **URL** | 打开网页 / 应用，`{text}` 替换为选中文本 |
| **脚本** | 首行声明语言（`#shell` / `#osascript` / `#python` / `#node` 等），选中文本经 `$OCTOPUS_TEXT` 传入 |
| **Agent** | 交给外部 AI Agent（Pi / Claude Code）在终端执行 |
| **复制路径** | 复制选中文件的路径（纯路径 / `file://` URL / 带引号 三种格式）|

### Agent 动作（进阶）

Agent 动作可以**召唤外部命令行 AI 工具**，prompt 支持占位符：

- `{{voice}}` —— 自动联动[语音听写](./asr-dictation.md)，录一段语音作为输入。
- `{{text}}` —— 选中的文本。
- `{{files}}` —— 选中的文件。

**典型用例——用嘴做 PPT**：

1. 在 Finder 选中一个文件（PPT 大纲 / 文档）。
2. 按 `⌥D` 唤起 Action Bar。
3. 执行配好的 Agent 动作（含 `{{voice}}` 占位符）。
4. 弹出语音录入 → 口述你的风格要求（「做成瑞士风，暖色调」）。
5. Action Bar 自动打开[终端](./terminal.md)，启动 Claude Code 等 agent，把文件 + 你的口述要求传给它生成 PPT。

> 详见 [`docs/features/make-ppt.md`](../features/make-ppt.md)。

### 内置密码生成器

输入框右侧的 🔑 按钮 → 打开[密码生成器](./vault.md#密码生成器)浮窗。

## 键盘导航

Action Bar 以键盘操作为主：

| 按键 | 作用 |
|------|------|
| `↑` `↓` | 上下移动结果 / 切换菜单项 |
| `⇥` / `⇧⇥` / `←` `→` | 切换分类标签（循环）|
| `↵` / `␣` | 执行选中项 |
| `⎋` | 清空搜索；菜单模式关闭浮窗 |
| `⌥1`–`⌥9` / `⌥字母` | 定位到第 N 个菜单项（标签上有 `⌥字母` 提示）|
| `/` 开头 | 斜杠命令模式（`Tab` 补全命令名）|

> 💡 中文顿号「、」开头会自动转成 `/`。输入法组合中按键会放行，不干扰打字。

> 点浮窗外部或窗口失焦会**自动关闭**。

## 搜索分类（标签栏）

顶部 7 个分类标签：

| 标签 | 定位符 |
|------|:------:|
| 全部 | `⌥A` |
| 应用 | `⌥D` |
| 文件 | `⌥F` |
| 书签 | `⌥B` |
| 动作 | `⌥Z` |
| 命令 | `⌥C` |
| 斜杠 | `⌥S` |

> 「动作」标签只在选中文本时显示；「斜杠」标签只在输入 `/` 开头时显示。

## 设置

### 命令面板管理

「设置 → 命令面板」：管理所有菜单动作——

- 新增 / 编辑 / 删除主菜单与子菜单。
- 配类型（AI / URL / 脚本 / Agent / 复制路径 / 扩展包 / 父菜单）。
- 设 `/` 命令名。
- **Quick Execute 全局快捷键**：跳过浮窗直接执行某个动作。
- 启用 / 隐藏。
- **适用场景**：文件 / 文本 / 文件+文本（控制何时显示）。
- **绑定应用**：只在某个 app 激活时显示，否则全局。
- 查看执行记录。

> 📷 **待补截图**（`images/actionbar-settings.png`）：命令面板管理（菜单动作列表 + 编辑）

### 智能体管理

「设置 → 智能体管理」：配置外部 AI Agent（Pi / Claude Code 等）的路径和适配器，「刷新检测」自动识别已安装的 agent。

### 搜索引擎

「设置 → 常规」里的默认搜索引擎（默认 Google），内置 `/google`、`/baidu`、`/bing`、`/github` 等斜杠命令。

### 索引范围

应用索引自动扫描系统应用目录，后台每 10 分钟检测变化自动重扫；文件走系统搜索；书签自动遍历浏览器——**无需手动配置索引范围**。

## 常见问题

**Q：按 `⌥D` 没反应？**
检查快捷键是否被占用，或在「设置 → 常规 → 快捷键」改一个。

**Q：搜不到某个应用？**
应用索引每 10 分钟自动刷新。新装的应用可以重启 octopus 立即触发重扫。

**Q：Agent 动作怎么配？**
先在「智能体管理」配好 agent 路径（如 Claude Code 的 `claude`），然后在「命令面板」新增一个 Agent 类型动作，prompt 里用 `{{voice}}` / `{{text}}` / `{{files}}` 占位符。

**Q：Quick Execute 是什么？**
给某个动作单独配一个全局快捷键，按下直接执行，不弹 Action Bar 浮窗。适合高频动作。

**Q：怎么让某个动作只在特定应用里出现？**
编辑动作时设「绑定应用」，它就只在该 app 激活时显示。
