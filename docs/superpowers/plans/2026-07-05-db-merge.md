# DB 表合并重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 用 superpowers:executing-plans 逐任务实施。

**Goal:** clipboard_history 吞并 transcriptions，精简为 content + ref_data + meta_info 三层模型。DROP + CREATE 不迁移历史数据。

**Architecture:** v16→v17 DROP 旧表 + CREATE 新表。store.rs CRUD 全改。coordinator/transcript 不再写 transcriptions。

**Tech Stack:** Rust + SQLite + rusqlite + serde_json。

**实施记录：**

- `types/clipboard.ts`：完全重写。删除 `Source` / `ImageMeta` / `FileMeta` / `AsrMeta` / `OcrMeta` 五个旧类型，改为统一 `MetaInfo`（image w/h/size、voice engine/model/duration_ms/char_count、file files 数组）。`ClipboardItem` 删 `source` / `image_meta` / `file_meta` / `asr_meta` / `ocr_meta`，加 `ref_data` / `meta_info` / `has_thumbnail` / `segments`。`ItemType` 加 `"voice"` / `"ocr"`。
- `ClipboardItem.tsx`：
  - 图标判断 `item.source === "asr"/"ocr"` → `item.item_type === "voice"/"ocr"`
  - `isVoice` 同理改 `item.item_type === "voice"`
  - 图片尺寸 `item.image_meta.width/height` → `item.meta_info?.w/h`
  - 文件路径从 `item.content` + `item.file_meta?.file_count` → `item.ref_data`（新 schema file 路径在 ref_data）
  - `formatFilePaths` 签名从 `(content, count?)` → `(refData?)`，count 改为从 `paths.length` 推导
- `ClipboardPanel.tsx`：
  - 同 ClipboardItem.tsx 的 source→item_type、image_meta→meta_info、file content→ref_data 改动
  - `item.asr_meta.engine` → `item.meta_info?.engine`
  - `item.image_meta.size`（number bytes）→ `item.meta_info?.size`（string 如 "2.3M"），删 `formatSize` 函数
  - `formatFilePaths` 同步改签名

**构建结果：** `tsc --noEmit` + `vite build` 全通过，0 error。

**未改动的文件（无需适配）：**
- `FilterTabs.tsx`：filter value `"asr"` 由后端 `build_where` 已映射为 `item_type = 'voice'`，前端无需改
